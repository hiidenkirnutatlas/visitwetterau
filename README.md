# Wetterau entdecken

Interaktive Karte mit Ausflugszielen, Geschichten und Videos aus der
Wetterau und dem angrenzenden Oberhessen.

## Inhalt

Die Website zeigt:

- Burgen und Schlösser
- Natur und Aussichtspunkte
- Fachwerkstädte
- historische Orte
- Ausflugsziele
- Orte der Landesgartenschau Oberhessen 2027
- Links zu Instagram und YouTube
